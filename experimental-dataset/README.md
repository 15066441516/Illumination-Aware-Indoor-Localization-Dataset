# Experimental Dataset
This directory contains the main experimental dataset associated with the paper "Illumination-Aware Low-Light Indoor Visual Localization System."
The dataset consists of ten indoor video sequences (Video1–Video10), covering different indoor environments and illumination conditions.
## Dataset Description
Video1–Video7: Low-light sequences, used to evaluate the structured-domain (RBS) branch.
Video8–Video10: Normal-illumination sequences, used to evaluate the original-image (RAW) branch and adaptive matching-budget strategy.
## Research Applications
The dataset supports research on illumination assessment, adaptive branch selection, feature matching, structure-from-motion (SfM) reconstruction, and indoor visual localization.
## Associated Paper
Illumination-Aware Low-Light Indoor Visual Localization System.
